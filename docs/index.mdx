Storeit is an asset management app. A Go backend (modular monolith) serves a Vue single-page app;
Postgres holds everything, and a worker sends email and runs background jobs.

Live at https://storeit.bigphu.io.vn. Release notes are on
[GitHub releases](https://github.com/bigphu/storeit/releases).
